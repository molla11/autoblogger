현재 상태: 개발 진행 중. 완료 보고서가 아닙니다.

확정 범위
- 1~6주차 기능을 구현하고 로컬에서 검증합니다. 실서비스 로그인·배포는 사용자 요청으로 이번에 진행하지 않습니다.
- 초기 AI: OpenRouter openai/gpt-6.1-terra / Azure. 자동 fallback 없음. 관리자 설정에서 이후 변경 가능.
- OpenRouter 인증 확인: $20 한도, 초기 잔여 $20. 키는 .env.local에만 보관합니다.
- Ghost CMS: https://cms.shinem.dev. 기존 webhook → https://shinem.dev 배포를 유지합니다.

개발 중 확인된 제약
- Docker 소켓 접근 불가. 기본 PGlite 외에도 독립된 실제 PostgreSQL16.15와 Redis7을 사용자 권한으로 실행했습니다.
- Ghost 기본 노드의 Lexical 0.13.1과 최신 BlockIdExtension은 호환되지 않습니다. 명세의 전환 조건에 따라 Tiptap + Ghost HTML 카드 경로를 사용합니다.
- Ghost Admin API: User-Agent를 명시해 조회 인증 성공. 서버 Ghost6.67. 운영 사이트 글은 변경하지 않았습니다.
- OpenRouter: Azure 지역 endpoint azure/eu로 지정한 모델 호출 성공. 상위 Azure 이름만으로는 라우팅이 거절되어 정확한 endpoint를 사용합니다.
- 실제 사람의 10개 세션, 베타 참여 동의, 독립 평가자 채점은 자동 생성하지 않습니다. 이식/mock 테스트와 정식 평가를 구분합니다.
